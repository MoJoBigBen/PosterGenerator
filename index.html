How do I get a TMDB API key?
  1. Create a free account at themoviedb.org and confirm your email address.
  2. Open Settings → API and request an API key. Choose the personal / non-commercial option and describe it as a private poster maker. For the website address you can enter the address of this page.
  3. Copy the API Read Access Token (a very long text) or the API Key (short). Either one works.
  4. Paste it into the “API key” field above. The tool remembers it in your browser, so you only do this once.

Keep the key to yourself. Everyone should get their own, it's free.

Help
  • Album: search for an album or drop in your own cover, check the texts, pick a background, export.
  • Film / series: search TMDB (needs a free API key, see the guide in the film tab) or drop in your own image. Pick a style, and set the format to match the image.
  • Moving text: drag any text on the film poster. “Dragging moves” sets what moves along. It snaps to the centre, the margins and other texts; hold Alt to move freely, double-click to reset.
  • Image: drag the image to move it, and use the slider to zoom. The dpi note below the buttons tells you how sharp it will print.
  • Export: PNG or PDF, 300 dpi is right for printing. In Chrome and Edge you can tick “Choose where to save”.
